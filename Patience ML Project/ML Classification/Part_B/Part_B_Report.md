# Part B: Customer Segmentation Analysis Report

## 1. Summary

This report details the process of segmenting customers from an online supermarket dataset (`Part_B_Dataset.csv`) using unsupervised machine learning. The goal was to identify distinct customer groups based on their purchasing behavior (items bought, discounts, time, category spending). Multiple clustering algorithms (K-Means, Agglomerative Clustering, DBSCAN) were evaluated using the Silhouette Score. K-Means with 9 clusters was selected as the final model based on the evaluation criteria implemented in the script. The analysis pipeline, cluster profiles, and instructions for using the saved model for future predictions are documented below.

## 2. Project Files

The following files were generated or used in this analysis:

*   **`Part_B_Dataset.csv`**: The raw input data containing anonymized customer purchase information.
*   **`part_b_clustering.py`**: The Python script containing the end-to-end pipeline: data loading, preprocessing, algorithm comparison, model training, evaluation, profiling, and artifact saving.
*   **`elbow_curve.png`**: A plot generated by the script showing the K-Means inertia for different numbers of clusters (k=1 to 10). Used visually to get an initial idea of potential optimal 'k' values (look for the "elbow" point).
*   **`silhouette_plot.png`**: A plot generated by the script (using the `yellowbrick` library) showing the Silhouette scores for each data point within the clusters identified by the final K-Means (k=9) model. Helps visualize cluster density and separation.
*   **`scaler_part_b.joblib`**: The saved `StandardScaler` object. This is crucial for preprocessing *new* customer data exactly the same way as the training data before making predictions.
*   **`clustering_model_part_b.joblib`**: The saved final K-Means (k=9) clustering model object. This is used to assign new customers to one of the 9 identified segments.
*   **`Part_B_Report.md`**: This report file summarizing the analysis.

## 3. Data Preparation

*   **Loading:** Data was loaded from `Part_B_Dataset.csv` using pandas. Initial shape: (30000, 14).

## 4. Clustering Algorithm Evaluation & Selection

Three clustering algorithms were evaluated using the **Silhouette Score**, which measures how similar an object is to its own cluster compared to other clusters. Scores range from -1 to 1, where higher values indicate better-defined clusters.

*   **K-Means:** Evaluated for k=2 to 10.
    *   Best Score: 0.1958 at k=9.
*   **Agglomerative Clustering (Ward linkage):** Evaluated for k=2 to 10.
    *   Best Score: 0.1382 at k=8.
*   **DBSCAN:** Evaluated with `eps` values [0.5, 1.0, 1.5, 2.0] and `min_samples=5`.
    *   `eps=2.0` yielded 4 clusters + 210 noise points, with a high Silhouette Score of **0.6955** calculated *only on the non-noise points*.
    *   Other `eps` values resulted in many noise points or lower scores.

**Selection:**
While DBSCAN (eps=2.0) showed a high Silhouette Score on its identified clusters, it classified a portion of the data as noise and found fewer clusters (4) than suggested by K-Means' peak score. DBSCAN is sensitive to parameters (`eps`, `min_samples`) and interpretation can be complex, especially with noise. The script's logic prioritized the highest score among K-Means and Agglomerative Clustering across the tested 'k' range, leading to the selection of **K-Means with k=9** (Score: 0.1958) as the final model for broader segmentation without explicit noise handling. *Further investigation into DBSCAN with fine-tuned parameters could be a potential next step if identifying outliers or density-based clusters is a primary goal.*

## 6. Persistence & Inference (Predicting New Customers)

The scaler and model were saved to allow prediction on new data without retraining.

*   **`scaler_part_b.joblib`**: Contains the `StandardScaler` fitted on the training data.
*   **`clustering_model_part_b.joblib`**: Contains the fitted `KMeans(n_clusters=9)` model.

**How to Predict Cluster for New Customer Data:**

```python
import pandas as pd
import joblib

# 1. Load the scaler and model
scaler = joblib.load('scaler_part_b.joblib')
model = joblib.load('clustering_model_part_b.joblib')

# 2. Prepare new customer data (Example - replace with actual data)
# Ensure it has the same 12 features IN THE SAME ORDER as used for training
new_data = pd.DataFrame({
    'total_items': [30, 50],
    'discount%': [10.5, 5.0],
    'weekday': [3, 6],
    'hour': [11, 16],
    'Food%': [25.0, 15.0],
    'Fresh%': [40.0, 60.0],
    'Drinks%': [15.0, 10.0],
    'Home%': [10.0, 5.0],
    'Beauty%': [5.0, 2.0],
    'Health%': [0.0, 1.0],
    'Baby%': [5.0, 2.0],
    'Pets%': [0.0, 5.0]
    # Add more customer rows as needed
})

# 3. Apply the SAME scaling
# Important: Use transform(), NOT fit_transform()
new_data_scaled = scaler.transform(new_data)

# 4. Predict the cluster
predictions = model.predict(new_data_scaled)

print("New Customer Data:")
print(new_data)
print("\nPredicted Clusters:")
print(predictions) # Output will be an array like [1, 3] corresponding to the cluster IDs
```
